# Contenido de proyectos

Guardar un archivo `.mdx` por proyecto en este directorio.

- Usar el nombre del archivo como slug publico.
- Mantener el frontmatter alineado con `specs/005-content-model.md`.
- Definir `order` para controlar el orden del listado publico.
- Guardar imágenes en `public/images/projects/` solo cuando sean propias o se tenga derecho a publicarlas.
- Registrar cada MDX nuevo en `src/content/projects/registry.ts` para habilitar su ruta pública.
- Seguir [`docs/CASE_STUDY_STANDARD.md`](../../../docs/CASE_STUDY_STANDARD.md): problema, decisiones, estado, evidencia y pendientes sin inventar resultados.
