# Feature 020 — FDE positioning foundation

## Objetivo

Establecer una fuente de verdad estratégica para actualizar progresivamente el portfolio: perfil actual de automatización e integración empresarial, uso responsable de IA como herramienta de ingeniería y evolución hacia roles FDE antes de octubre de 2027.

## Punto de partida verificado

El portfolio actual destaca Android y ZIBE. El trabajo más reciente del autor aporta evidencia en automatización financiera con Python, Excel/VBA, integraciones empresariales y herramientas de IA para asistir el desarrollo. El perfil público no está actualizado a octubre de 2026.

## Mensaje acordado

**Hoy:** Automation & Software Developer | AI-Assisted Engineering | Enterprise Integrations.

**Dirección de crecimiento:** Forward Deployed Engineering | Enterprise Automation & Applied AI.

La dirección de crecimiento **no** es el cargo ni el nivel de experiencia que se declara hoy. No reemplazar evidencia con palabras aspiracionales.

## Matriz inicial de capacidades y evidencia

| Área | Evidencia conocida | Estado editorial | Prueba que falta o debe fortalecerse |
| --- | --- | --- | --- |
| Discovery y criterio funcional | Trabajo en AP/P2P y Finanzas, relevamiento de reglas y excepciones | Fortaleza actual | Casos con decisiones y validación por usuarios, redactados de forma segura |
| Automatización de procesos | Caso público Migrar SAP; Finance Toolkit privado en desarrollo | Fortaleza actual | Caso público seguro con alcance, estado e impacto verificable |
| Python e integraciones | Excel/VBA ↔ Python, automatización web, archivos y Google Workspace en proyectos reales | Uso aplicado | Pruebas, contratos y tratamiento de errores descritos en un caso público |
| Ingeniería y calidad | Git, documentación, tests y arquitectura por responsabilidades en repos | En consolidación | Evidencia pública consistente de diseño, pruebas y mantenimiento |
| SQL, APIs y despliegue | Algunas herramientas y experiencias parciales; evidencia heterogénea | Brecha a validar | Proyecto desplegado con datos, API, observabilidad básica y pruebas |
| IA asistiendo desarrollo | Uso de ChatGPT, Claude y Gemini para análisis, diseño, código y revisión | Metodología actual | Ejemplos concretos de qué se verificó y qué decisiones tomó el autor |
| LLMs integrados en producto | Sin caso de producción verificado en este portfolio | Objetivo de aprendizaje | Integración API + evaluación + costos, fallos y límites; adopción si existe |
| Delivery con usuarios externos | Experiencia de coordinación y usuarios internos; sin evidencia validada de delivery FDE externo | Brecha a construir | Descubrimiento, implementación, adopción y resultado medible |
| Android y aplicaciones | ZIBE, Next.js y otros proyectos públicos/privados | Evidencia complementaria | Actualizar estado sin presentarlos como especialidad principal |

Las categorías no sustituyen una evaluación técnica ni acreditan dominio experto.

## Horizonte de desarrollo profesional

- **Oct–Dic 2026:** fundamentos y narrativa; Python, pruebas, SQL, HTTP y APIs.
- **Ene–Mar 2027:** construir/desplegar software de punta a punta con datos, API y validación.
- **Abr–Jun 2027:** implementar IA aplicada con LLMs y evaluaciones reproducibles.
- **Jul–Sep 2027:** casos defendibles, system design, discovery, inglés profesional y postulación a FDE o roles puente.

Son objetivos de preparación, no logros alcanzados.

## Alcance de esta feature

**Incluye:** `docs/PROJECT_CONSTITUTION.md`, estos documentos de alcance, matriz, criterios y plan.

**Excluye:** modificar copy público, crear proyectos, editar el PDF del CV, cambiar layouts, instalar dependencias, migrar repositorios, añadir infraestructura o publicar material corporativo.

## Criterios de aceptación

1. La constitución define el perfil actual y el objetivo FDE sin confundirlos.
2. IA asistida e integración de LLMs están diferenciadas.
3. Las brechas y evidencias están registradas honestamente.
4. Las siguientes iteraciones cuentan con alcance y orden definidos.
5. La arquitectura existente permanece intacta.
